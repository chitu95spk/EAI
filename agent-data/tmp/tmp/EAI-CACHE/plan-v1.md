# EAI-CACHE-r1-plan-v1 (route standard; NOT yet approved)
User request 2026-10-11: "add image caching for training sessions and later work sessions so they are faster".
User decisions: priorities = training start, auto-label/inspect batches, canvas image switching, project open; location = <project>\.easyai\cache, max 2 GB, oldest-first cleanup, limit editable in Settings; training cache stores metadata and hashes only (no pixels). Discovery: tmp/EAI-CACHE/discovery.md.
Invariants: EasyLabel only; no behavior change of training results (hashes/fingerprints must be byte-identical to today's); cache is disposable (delete = slower, never wrong); every entry keyed by file length + LastWriteTimeUtc ticks (+ model file stamp + class-table suffix where relevant); corrupt entry ignored; writes atomic; cleanup never touches non-cache files.
C1 Image meta cache (project open): <project>\.easyai\cache\image-meta.json {rel -> length, ticks, width, height}. SegAiSession.GetImageSize/BuildInfo read it before decoding; persists debounced. Removes O(N) full decodes at open. Tests: SegAI.Tests (hit, stale by length/ticks, corrupt file).
C2 Canvas preview cache: in-memory LRU of decoded frozen BitmapImages inside ImagePreviewLoader (cap by bytes, default 256 MB, and by count), key = path+length+ticks; prefetch next/previous image on idle; keeps cancel-on-new semantics. Tests: pure LRU class tested in SegAI.Tests (linked file) or Core.Tests.
C3 Training: (a) measure first with SegAiRealDatasetTimingTests-style timing (decode, snapshot PNG encode, PngHash, RawMatHash, per-class compare) on a project fixture, written to artifacts/EAI-CACHE/; (b) only then: persist per-frame hashes in <project>\.easyai\cache\train-frames.json keyed by image stamp + mask stamp + class table, so unchanged frames skip PNG re-encode and hashing; keep decode-once where memory allows. Tests: Retrain_* family unchanged, hashes identical with and without cache.
C4 Auto-label/Inspect results on disk: <project>\.easyai\cache\results\<key>.json (suggestions/regions only, small), key = existing stamps (image stamp, model file stamp, thresholds, ClassCacheSuffix); loaded into the existing in-memory LRUs; invalidated by any key change. Tests: AutoLabelServiceTests/InspectServiceTests extended.
C5 Governance: Settings 'Cache' (max size default 2 GB, Clear cache button, current size); oldest-first cleanup on project open in the background; never deletes outside .easyai\cache.
Order: C1, C2, C3a (measure), C4, C3b (if measurement justifies), C5. Each slice commits separately; evidence = EasyAI.Wpf build + 4 EasyLabel test projects; UI smoke only for C2 and C5 (idle PC).
Open: speed gains are unmeasured until C3a; real numbers will be reported before/after.
