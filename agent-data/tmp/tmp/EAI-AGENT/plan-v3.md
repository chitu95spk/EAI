## Decisions (user approved the recommendations)
D1 session = one continuous chat view per project, runs still stateless (agent gets current shapes + pending suggestions, not earlier turns). D2 /clear clears history file + view, no confirm; memory and outcome log stay. D3 parallel batch DEFERRED. D4 duplicate rule: reject an added box if IoU >= 0.5 with an existing shape or pending suggestion (any label), or >= 80% covered by one of the same label; a small part inside a larger part with a different label is allowed. D5 Remaining enabled only after a successful agent run on the current image (this session / chat history) and then excludes that image.
