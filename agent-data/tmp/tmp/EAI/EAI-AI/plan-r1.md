## Slices (each ends in a green build + tests + commit; one writer at a time)
- **S1 Source selector (UI + wiring, simple/UI):** panel Auto-label gets a segmented option AI Model | Segment Model | Agent Prompt (production custom control, no stock ComboBox). Per source: Segment Model = existing active-model auto-label; AI Model = SAM2/YOLO-World model picker + enable state; Agent = prompt textbox + Run. AI-Box/AI-Points read the same source; AI-Points disabled unless the source supports point prompts (SAM2 only; text/YOLO-World and Segment do not). Persist choice in settings. Unavailable sources show the existing "Unavailable: ..." text with the reason. Tests: view-model rules (which tool is enabled per source).
- **S2 AI model backend (complex):** new project EasyLabel.Ai (net9) with ONNX Runtime GPU (DirectML vs CUDA EP: decide in architect pass; machine has RTX A500 Laptop, ~4 GB VRAM, so SAM2 **tiny/small** only, encoder+decoder split, CPU fallback). SAM2: image encoder cached per image, decoder per prompt (box or points). YOLO-World: text-prompt open-vocabulary boxes (ONNX export; fixed vocabulary per run). Models in `%LOCALAPPDATA%\EasyAI\models\{sam2,yolo-world}` (already shown in Settings); download helper script like tools/DownloadRapidOcrModels.ps1; models are NOT committed. Result -> polygon/box suggestions through the existing suggestion path. Tests: pre/post-processing against fixed tensors; model-dependent tests skipped when files are missing; latency evidence owed on hardware.
- **S3 Agent over MCP (complex):** EasyAI hosts a local MCP server (stdio child process per run or loopback HTTP; choose in architect pass, default stdio so nothing listens on a port). Tools (small outputs): get_image_info, get_image_crop(x,y,w,h,scale), get_labels/classes, list_shapes, propose_shapes(kind,label,points,confidence) (writes only to the suggestion layer, never to the saved JSON), run_sam2(prompt), run_yolo_world(text) when S2 is ready, find_edges/threshold helpers (OpenCV). EasyAI spawns `claude -p` with `--mcp-config` pointing at this server and a restricted tool allow-list, the prompt, and an output schema; result = suggestions the user accepts/rejects. Login: reuse the user's Claude Code login; if `claude` is not found or not logged in -> source shows "Unavailable: Claude Code not installed / not signed in" with the fix text. Skill pack: a project skills folder shipped with the app (read image, detect object, crop-and-zoom, measure, label-naming) loaded by the agent via the same run (`--add-dir`/skills), so repeated procedures cost no re-explanation. Token economy: crop+downscale before sending, per-image result cache keyed by image hash + prompt + model, batch mode sends one image per call with a shared system prompt (cache-friendly).
- **S4 Hardening:** timeouts, cancel (kills the child process), error text, no secrets in logs, UI smoke (vi/en, 100% and 150% DPI), evidence.

## S3 spike evidence + design (2026-10-08)
Spike (tmp/EAI/EAI-AI/s3-spike): the bundled Claude Code 2.1.292 `claude.exe -p` ran headless with the user's existing login, loaded a stdio MCP server through `--mcp-config cfg.json --strict-mcp-config`, called its tool (`--allowedTools mcp__easyai__ping`) and returned the tool result (exit 0, 3 turns). Stop condition NOT triggered.
Cost finding: default flags cost $0.043/run (about 18k cache-creation tokens of Claude Code baseline); with `--tools "" --system-prompt <own> --disable-slash-commands --setting-sources "" --no-session-persistence` the same call cost $0.0087 (7k input, no cache write). S3 must use the minimal flag set. `--output-format json` gives total_cost_usd, usage, num_turns for the per-run log.
Design (no IPC): EasyAI creates a run folder `%LOCALAPPDATA%\EasyAI\agent-runs\<guid>\` with request.json (image path, class names, existing shapes, models folder). `claude -p` is started with an MCP config whose server is the new console exe `EasyLabel.Ai.Mcp` (hand-written JSON-RPC over stdio, Newtonsoft, no new package) given `--run <dir>`. Tools: get_image_info, get_crop (JPEG image block, max side default 768), list_shapes, sam2_segment (box/points -> polygon via EasyLabel.Ai.Onnx), propose_shapes (writes proposals.json, never the project files). After the process ends EasyAI reads proposals.json into the suggestion layer. Skill pack = markdown procedures concatenated into `--append`/`--system-prompt` (read image -> crop/zoom -> propose; detect objects; naming labels). Claude discovery order: setting override, PATH, %USERPROFILE%\.claude\local, newest VS Code extension folder. Scope revision: new projects `EasyLabel/src/EasyLabel.Ai.Mcp` and `EasyLabel/tests/EasyLabel.Ai.Mcp.Tests` added to the contract.
Slices: S3a = MCP server project + tests with scripted stdin (no claude, no UI); S3b = AgentRunner service (discover, spawn, cancel, parse json, cost log), prompt box Run, reasons, flip IsBackendImplemented(Agent), UI smoke with a real claude run.
