# EAI-1 implementation plan — revision EAI-1-r1-plan-v1 (architect opus, saved by root 2026-10-05)

Goal: UI-free Segment AI backend in EasyLabel.SegAI (net9.0-windows, LangVersion 12): native wrappers, model-file utilities, dataset types/storage, rasterizer, EasyVision dataset import/export, LabelMe converter (+ sidecar/raster for holes), plain inference, V1/V2 training + retrain + evaluation, parity harness vs EasyVision.

## Scope
IN: native wrappers; model-file utils; SegAnnotation/SegSample/options/report; raster rasterize/read; EasyVision dataset import (folder+zip) and export (zip only); LabelMe converter; plain inference (whole image or axis-aligned ROI) incl. AnalyzePrediction/AnalyzeNormalPrediction; configured training V1 structural + V2 incl. retrain and evaluation; parity harness.
DEFERRED: label rules + multi-region + rotated Check/Cropper/ToolInputSession preprocessing (EAI-5); SuggestAnnotation (EAI-3); TrainingRecommendation + full registry state machine (EAI-4); overlay rendering (UI); legacy RTrees path (dropped); SegmentAIEngineRunner (EasyVision glue).

## Verification and parity meaning
Build/test per slice: dotnet build EasyLabel.sln -c Release (log to artifacts/EAI/EAI-1/<run>/), 0 errors; dotnet test: 41 Core + 5 SegAI + new tests.
Parity proves: wrapper + settings sequence + post-processing equal EasyVision SegmentAI.DoWork(Mat, Rect) full-image, GPU off, same DLL/model/image. Tolerance: native mask/confidence/normal bytes bit-exact; filtered masks bit-exact; regions sorted by (Y,X,area) bounds+area exact; scores |Δ|≤1e-6; IsOK equal; raster from annotations bit-exact (OpenCV 4.11 vs 4.13 FillPoly). NOT proven: rotated/masked Check, ToolInputSession pipeline, label rules, BestObjectOnly, counter/limits, GPU, training equivalence (only "loadable" + settings-JSON byte test), UI. If native mask itself differs → stop and report (no tuning).
Train smoke: V1 4 images (seconds, <300 MB); V2 4 images, Epochs=5, InputSize 320, GPU off (<2 min, ~1 GB; needs OpenVINO + onnx). Failure modes: error 126 c10, missing backbone, "requires NG and OK" (V1), cancel leaves no candidate, old DLL without ConfigureV2.

## Risks
OpenCV 4.11 vs 4.13 drift; bin/Release DLL may need c10/torch import DLLs (use extra folder, log probes); NativeSegAiFact triggers OpenVINO/GPU init (force SetGpu(false)); dot-folder skip could hide user images in dot-folders; cloned-code divergence (headers, periodic diff); runs/ growth (keep last 5 failure records); ref48 harness must not touch Global/persistence or bin/Release as output dir.
