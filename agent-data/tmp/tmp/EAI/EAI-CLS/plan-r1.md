## 1. Target semantics
- Class table stored in the model: id 0 = background, ids 1..N: name, kind (DEFECT / GOOD). OK is a GOOD-kind class (at most one GOOD class is required for the current "compare normal" behaviour; zero or one). Every other class is a DEFECT-kind named class (NG is just the default defect class name). N <= 32.
- Inspection verdict (EasyVision and EasyAI Inspect): NG when at least one region of ANY defect class passes the filters; OK otherwise. Per class counts and scores are reported. Old 2-class models behave exactly as today.
- Label rasters: pixel value = class id 0..N (uint8). Old rasters (0/1/2) stay valid (1 = NG, 2 = OK) and are mapped through the project's class table by name.
- File compatibility: `.segai` format version bump with a class table; the new native reads old 2-class models unchanged; old native/old EasyVision builds reject new-format models with a clear message (never misread).
