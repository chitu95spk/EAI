# EAI-UI plan r3 (draft, awaiting user approval) - feedback round on the Labelme layout

Builds on r2 (commits A-D + look pass, last 0a13edd19). User feedback 2026-10-08 (screenshots of the real build at 2000 px): buttons are not uniform; the EasyAI panel is not wanted (no statistics) - gather its feature buttons into the top menu; remove the Cờ (Flags) panel; Train/Val buttons directly in the file list to set each file; shortcuts exactly like Labelme; gradient colours from the logo, customizable in Settings (default = logo).
Logo colours (sampled from the supplied PNG): solid navy **#001E74** on white, no gradient in the file.

## 1. Changes
1. **Uniform buttons.** Toolbar buttons: one fixed size (height 56, width 64, 18 px icon, caption max 2 lines, centred) for every button in the main toolbar, left tool strip (width 72, equal heights), AI group controls (equal height 28) and step bar. Spin box and combo heights match. Verified by screenshots en+vi at 100% (and 150% only if the user sets scaling).
2. **EasyAI dock panel removed** (dataset statistics card, Engines block already in About). The stepper/step bar (Data/Label/Train) and the NG/OK selector leave the toolbar area: classes are picked in "Danh sách Nhãn" like Labelme. The EasyAI features move to the top **EasyAI menu** and open as windows that reuse the existing, tested view models/views (no logic rewrite):
   - Nhập dataset..., Thêm ảnh (also in Tệp), Nhập model... (file dialog, existing ImportModel), Chọn model (submenu of registry entries, SetActiveModel).
   - **Gán nhãn tự động...** opens a non-modal tool window "Gán nhãn tự động" = the current Label step content (model, current image / all unlabelled, threshold slider, progress+cancel, Accept all/selected, Reject all); shortcuts in the menu.
   - **Huấn luyện...** opens a window "Huấn luyện" = the current Train step content (options, Start/Stop, live charts, candidates, comparison, Use this model). Closing it while training asks to stop (existing rule). Train/Val counts shown in its header.
   - Stats (Train/Val/Ignored/Stale/Missing JSON) are not shown anywhere except the Train window header (needed to explain a disabled Start); the data summary card is dropped.
3. **Cờ panel removed** (menu item `Cờ` removed from Xem too); the LabelMe image-flags code, Settings row 'Cờ hình ảnh định sẵn' and Flags data stay in Core but the row is hidden until a Flags UI exists (rule: no dead control). Docking layout schema -> 3 (old layouts rebuilt once). Remaining panels after 3b: Danh sách Nhãn/Hình dạng (merged) and Danh sách Tệp.
3b. **Labels + Shapes merged into ONE panel "Danh sách Nhãn / Hình dạng"** (user request after the first draft): a two-level list. Level 1 = label rows (colour dot, name, count of shapes on the current image; NG and OK always present); clicking a label row makes it the active class (replaces the NG/OK selector). Level 2 = the shapes under their label (visibility checkbox, kind text polygon/rotation/..., 'ignored by Segment AI' marker for non-NG/OK), click selects the shape, Delete uses the real command; label rows are collapsible and have a checkbox that shows/hides all their shapes (view-only flag). One panel title bar, one splitter; the right column becomes: Nhãn/Hình dạng (tall) + Tệp. Docking ids: `labels` and `shapes` merge into `labels` (View menu keeps one item). Layout schema 3 rebuilds old layouts once. AutomationIds ClassList (label list) and a new ShapeList kept.
4. **Train/Val per file:** each row of Danh sách Tệp gets a two-button segmented control **Train | Val** (current mode highlighted) that calls the existing SetMode for that file (not only the selected one), enabled only for images that have regions (disabled otherwise with the existing 'ignored' text state); updates counts/badge immediately; one-click, no undo unit (as Space today). The plain-text badge column keeps showing Ignored/Stale. Space shortcut removed (Labelme has none).
5. **Shortcuts exactly Labelme.** Keep only Labelme's: Ctrl+O, D (next), A (prev), Ctrl+U, Ctrl+S, Ctrl+Shift+S, Ctrl+W, Ctrl+Del, Ctrl+Shift+, , Ctrl+Q, Ctrl+N (polygon), Ctrl+R (rectangle), Ctrl+J (edit shape), Ctrl+Z, Ctrl+Z while drawing (undo last point), Ctrl+C, Ctrl+V, Ctrl+D (duplicate), Ctrl+E (edit label), Del, Meta+H (delete vertex), Ctrl+Up/Down/Left/Right (select shape), Ctrl+P (keep previous annotation), T (toggle shapes), Ctrl++, Ctrl+-, Ctrl+0, Ctrl+F (fit window), Ctrl+Shift+F (fit width), Enter/Esc/Backspace while drawing (Labelme behaviour). **Removed:** plain V/R/O/P/F/1/2, Tab/Shift+Tab selection cycling, Space, plain arrow nudge of selected shapes (Labelme arrows move nothing; Up/Down arrows keep stepping files only if Labelme does - it does not, so removed), Ctrl+A select-all stays only if Labelme has it (it has none in the menu: removed), Ctrl+Y redo (removed; Redo stays as menu/toolbar button). Tools without a Labelme shortcut (rotated rect, circle, point, line, linestrip) have none. EasyAI-only commands get Ctrl+Alt combinations shown in the EasyAI menu (Auto-label Ctrl+Alt+L, Train Ctrl+Alt+T, Import dataset Ctrl+Alt+I). A shortcut table test (UI-free) asserts the bindings equal this list.
6. **Logo gradient theme + Settings.** New `ThemePalette` (UI-free, tested): AccentColor (default #001E74), GradientStart (default #001E74), GradientEnd (default #5C86E0), BackgroundTint (default #EEF2FB), text-on-gradient white. Applied to: window title/menu band (gradient start->end, white text), toolbar background (light tint of the gradient), selected states/primary buttons/panel title bars (accent), canvas surround. Light and dark modes both derive from the palette (dark = accent darkened). The Settings page 'Giao diện và ngôn ngữ' gains: Màu nhấn, Màu gradient bắt đầu, Màu gradient kết thúc, Màu nền, 'Đặt lại theo logo' (button) - colour rows use the existing colour-picker control pattern used for 'Màu của chế độ Đồng nhất' (WPF-UI ColorPicker-less: hex text + swatch + a real colour dialog). Persisted in AppSettings with defaults = logo colours; changes apply live.
7. **Window/app icon** = the supplied logo (navy rounded square with white A): set as the EasyAI.exe icon, window icon, About logo; logo asset stored in the project (src/EasyAI.Wpf/Assets). The user gave the image path; copy it into the repo as `EasyAI.ico`/png (generated from the PNG).

## 3. Risks
- Moving Step views into windows changes how smoke scripts reach them (harness update, not product risk). Windows are non-modal tool windows owned by the main window; the training lock/IsBusy rules stay.
- Removing plain-key shortcuts changes muscle memory (user asked for it).
- Gradient on a WPF-UI FluentWindow (Mica/backdrop): title/menu band painted by our brushes; if the backdrop shows through, set Backdrop to None for the band. Contrast (white text on gradient) checked in both languages.
- 150% DPI unverified unless the user sets scaling.
