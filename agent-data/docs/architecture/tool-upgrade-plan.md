## Shared processing design

- Defect analysis consumes a binary mask and optional exclusion mask. Return independent count, pixel area, centroid, bounds and oriented extent. Use connected components and contour geometry from existing OpenCvSharp. Extent is not scratch-path length; colored overlays are never interpreted as binary masks.
- Geometry adapters expose existing point/line/circle/contour output with source identity, coordinate frame and validity. Keep fractional geometry to the calculation boundary and round only for display. Preserve old serialized selections and native signatures.
- Resolve pixel/mm versus mm/pixel once at the calibration adapter boundary. Preserve pixel operation when metric calibration is unavailable, with truthful units.
- Distinguish valid absence, failed acceptance and processing failure. Reuse current result/error paths. New result metadata is runtime-only. New persisted settings require optional/versioned defaults and clone/round-trip tests.
- Reference, spot and scratch alternatives remain opt-in. Retain current native comparison and parameters for legacy mode. No automatic dependency or model replacement.
