# Third-party DLLs in the installed SegAI directory

Audit date: 2026-11-11. Scope: `EasyLabel/Lib/native/segai`, 47 top-level DLL files plus two model files. This is an evidence-based redistribution inventory, **not a statement that the current installer has fulfilled every license obligation**. No production/native files were changed.

## Evidence and version attribution

- Installed/pre-replacement manifests: `tmp/EAI-SEGAI-CUDA/production-build2/results/app_after.csv` and `app_before.csv`.
- Independent current hashes: `tmp/EAI-SEGAI-CUDA/laneB/inventory*.json` (see verification report for completeness).
- `tmp/EAI-SEGAI-CUDA/laneB/license-provenance.json` compares original wheel `RECORD` SHA256 entries with the installed deployment manifest. **All 18 NVIDIA DLL entries match** the seven package versions below. This is stronger than guessing a version from a DLL filename. It does not replace a fresh hash of the installed bytes.
- The OpenVINO 2025.4.0 wheel in the scratch Python environment does **not** hash-match the installed OpenVINO/TBB DLLs. Therefore its version must not be assigned to the installed files.
- The official libtorch archive used for the replacement contains `libtorch/build-version` = `2.14.1+cpu`; downloaded file is `libtorch-win-shared-with-deps-2.14.1+cpu.zip`. The archive has no filename containing LICENSE/NOTICE; do not assume that shipping the DLLs alone supplies required notices.
- Local NVIDIA package EULAs and metadata were copied, read-only, to `tmp/EAI-SEGAI-CUDA/laneB/licenses/nvidia_*.dist-info-{License.txt,METADATA}`. Official upstream sources and notices were saved under the same directory; source URLs are in `sources.json`.

## Packaging conclusion

CUDA toolkit redistributables, ORT, OpenCV and the open-source project portions have redistribution paths subject to their stated notices/terms. **A complete ready-to-ship third-party notice bundle is not proven**: cuDNN 9's exact Windows list, Intel OpenMP binary terms, installed OpenVINO/TBB binary provenance, and libtorch embedded third-party notices remain open. This report does not modify deployment or add licenses to the installed directory.
