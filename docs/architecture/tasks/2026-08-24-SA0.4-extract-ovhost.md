## `ov/OvHost.h`

```cpp
#pragma once
#include <openvino/openvino.hpp>
#include <string>
#include <vector>
#include <map>
#include <mutex>

namespace BeeAi {

enum class DeviceMode { GpuAuto = 0, Cpu = 1, Auto = 2 };

struct OvHostConfig {
    std::wstring xmlPath;
    DeviceMode   device        = DeviceMode::GpuAuto;
    int          cacheGroup    = 0;      // separates CompiledModel per program/lane
    int          numThreads    = 2;      // requested CPU budget; see cap rule below
    bool         useAccuracy   = true;   // GPU execution-mode hint
    std::string  cacheDir      = "./ov_cache";
    int          inferRequests = 0;      // 0 = plugin default
    int          inferStreams  = 0;      // 0 = plugin default
};

struct OvIoInfo {
    ov::element::Type inputType = ov::element::f32;
    int inputN = 1, inputC = 3, inputH = 0, inputW = 0;
    std::vector<ov::Shape>   outputShapes;
    std::vector<std::string> outputNames;
};

class OvHost {
public:
    OvHost() = default;
    ~OvHost() { Close(); }
    OvHost(const OvHost&) = delete;
    OvHost& operator=(const OvHost&) = delete;

    bool Open(const OvHostConfig& cfg, std::string& outError);
    void Close();
    bool IsOpen() const { return opened_; }

    const OvIoInfo& Io() const { return io_; }
    std::string ResolvedDevice() const { return resolvedDevice_; }

    void*  InputData();                       // borrowed; valid until the next Infer()
    size_t InputByteSize() const;

    bool Infer(std::string& outError);
    const ov::Tensor& Output(size_t index) const;
    void Warmup(int iters);

private:
    bool opened_ = false;
    std::string resolvedDevice_;
    OvHostConfig cfg_;
    OvIoInfo io_;
    ov::Core core_;
    std::shared_ptr<ov::Model> model_;
    ov::CompiledModel compiled_;
    ov::InferRequest infer_;
    ov::Output<const ov::Node> inputPort_;
};

} // namespace BeeAi
```

## `ov/OvHost.cpp` — the seven behaviours, with exact values

These are transcribed from the working YOLO implementation. Use them as written.

**B1 — CPU thread cap.** A CPU-only lane gets the full budget; any GPU-capable lane is capped at 2 so it cannot starve a parallel GPU lane.
```cpp
const int cpuThreads = (cfg.device == DeviceMode::Cpu)
    ? std::max(1, cfg.numThreads)
    : std::max(1, std::min(cfg.numThreads, 2));
```
Default `numThreads` is **2**, not 8 — the production line box has 2 cores.

**B2 — Config maps.**
```cpp
ov::AnyMap gpuConfig;
gpuConfig[ov::hint::performance_mode.name()] = ov::hint::PerformanceMode::LATENCY;
if (cfg.useAccuracy)
    gpuConfig[ov::hint::execution_mode.name()] = ov::hint::ExecutionMode::ACCURACY;
if (inferRequests > 0) gpuConfig[ov::hint::num_requests.name()] = (uint32_t)inferRequests;
if (inferStreams  > 0) gpuConfig[ov::num_streams.name()]        = ov::streams::Num(inferStreams);
gpuConfig[ov::cache_dir.name()] = cfg.cacheDir;

ov::AnyMap autoConfig = gpuConfig;
autoConfig[ov::inference_num_threads.name()] = cpuThreads;

ov::AnyMap cpuConfig;
cpuConfig[ov::hint::performance_mode.name()]  = ov::hint::PerformanceMode::LATENCY;
cpuConfig[ov::inference_num_threads.name()]   = cpuThreads;
cpuConfig[ov::cache_dir.name()]               = cfg.cacheDir;
```

**B3 — Device policy.** Device strings are exactly `"CPU"`, `"GPU"`, `"AUTO:GPU,CPU"`.
```
Cpu     -> compile "CPU" with cpuConfig                     -> resolvedDevice_ = "CPU"
Auto    -> compile "AUTO:GPU,CPU" with autoConfig           -> resolvedDevice_ = "AUTO:GPU,CPU"
GpuAuto -> try   compile "GPU" with gpuConfig               -> resolvedDevice_ = "GPU"
           catch(const std::exception&) log the reason, then
                 compile "AUTO:GPU,CPU" with autoConfig     -> resolvedDevice_ = "AUTO:GPU,CPU"
```
Catch `const std::exception&` on the GPU attempt only. Any other failure is a genuine `Open` failure.

**B4 — Process-wide compiled-model cache.** A `static std::map<std::wstring, ov::CompiledModel>` plus a `static std::mutex`. Key fields, in this order: xml path · inputH · inputW · cpuThreads · inferRequests · inferStreams · cacheGroup · device-policy string · useAccuracy flag.

Device-policy strings for the key (distinct from the compile string so a cache entry cannot be shared across policies):
`L"CPU"` · `L"AUTO_GPU_CPU_MODEL_PRECISION"` · `L"GPU_FIRST_AUTO_FALLBACK_MODEL_PRECISION"`

> **Trap 1.** Instances sharing a key share the `CompiledModel` but **each must call `compiled_.create_infer_request()` for itself**. Sharing one `InferRequest` silently serialises two lanes that should run in parallel.
>
> **Trap 2.** Hold the mutex around the map lookup and the insert **only — never around `compile_model` itself**. Compiling takes seconds; holding the lock across it makes two lanes warming different models block each other.
>
> Correct shape: lock → look up → unlock. On a miss: compile outside the lock → lock → insert (tolerating another thread having inserted first) → unlock.

**B5 — Env overrides.** Clamped-int reader, values clamped to **[0, 2]**, default 0:
`BEE_AI_INFER_REQUESTS` → `inferRequests`, `BEE_AI_GPU_STREAMS` → `inferStreams`.
Names must use the `BEE_AI_` prefix — `BEE_ONNX_*` belongs to the YOLO board and the two must tune independently.

**B6 — Ports and I/O info.** After compiling: `infer_ = compiled_.create_infer_request();` `inputPort_ = compiled_.input();` `io_.inputType = inputPort_.get_element_type();`. Read the input shape from the compiled port; when it has rank 4, populate `inputN/C/H/W` from it. Populate `outputShapes` / `outputNames` from `compiled_.outputs()`.

**B7 — f32 and f16.** `InputByteSize()` returns `N*C*H*W * (io_.inputType == ov::element::f16 ? 2 : 4)`. `InputData()` returns the raw pointer of the input tensor so callers write CHW directly with no intermediate copy.

**Explicitly NOT in `OvHost`:** letterboxing · BGR→CHW conversion · YOLO or any decode · NMS · `metadata.yaml` parsing · anything touching `cv::ocl` global state. Those are model-specific and belong above this layer.

**Failure contract (plan §1.1 C6).** On any failure `Open` returns false, sets a non-empty `outError`, and leaves the object fully closed — no partially-open state. `Infer` on a closed host returns false and does not crash.
